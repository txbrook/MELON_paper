# dataset_info

This folder contains the copied dataset-information package from the original `deliverable` folder.

Contents:

- `datasets.md`: readable dataset summary
- `datasets.tex`: LaTeX version of the dataset appendix
- `references.bib`: bibliography entries used by the dataset appendix
- `pic/he/`: tissue or H\&E images used by `datasets.tex`
- `pic/anno/`: annotation and legend images used by `datasets.tex`

This folder is reference material only. It is not used by the main `neurips_2024.tex` build unless you explicitly merge content from it.
